# S06. Дополнительное подтверждение безопасности CampusPass — M3

## Проверяемое свойство

Цепочка `T-07 → SR-07 → D-05`: мероприятия в состоянии `draft` не должны попадать в публичный список `GET /api/events`.

## Выполненные проверки

Добавлены два автоматических теста в `tests/CampusPass.Api.Tests/EventVisibilityM3Tests.cs`:

1. При наличии только черновиков API возвращает пустой список.
2. При наличии опубликованных мероприятий и черновика API возвращает только опубликованные мероприятия в порядке даты начала.

## Среда и запуск

- Среда: macOS, .NET 10.
- Команда: `dotnet test tests/CampusPass.Api.Tests/CampusPass.Api.Tests.csproj`.
- Результат: 7 тестов пройдено, 0 ошибок, 0 пропущено.
- Время выполнения тестов: 1,9 секунды.

## Предупреждения

При сборке обнаружены предупреждения `NU1902` и `NU1903`, связанные с известными уязвимостями зависимости `System.Security.Cryptography.Pkcs` версии 9.0.0. Требуется отдельная проверка и обновление зависимости.

## Вывод

В проверенных сценариях серверная фильтрация черновиков работает корректно. Проверки не охватывают просмотр мероприятия по прямому ID, регистрацию, авторизацию и поведение реальной PostgreSQL.
