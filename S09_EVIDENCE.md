## Цепочка автоматизированной проверки AVC-S09-01

**Цепочка проверки: версия проекта → запуск → результат → решение → повторная проверка.** Для commit `1a8a3a1` Semgrep прошёл по 9 отслеживаемым C#-файлам приложения, с `--config auto` и 80 применёнными правилами. JSON не содержит находок и ошибок. Поиск Gitleaks по доступной Git-истории также завершился без находок. Поэтому подтверждённой SAST-уязвимости или утечки в рамках этих проверок **не обнаружено**, исправления в код не вносились; искусственная уязвимость не создавалась. Затем без изменений исходного кода повторно выполнен Semgrep с теми же параметрами (0 сигналов) и выполнены регрессионные .NET тесты (5/5). См. [`S09_FINDINGS.md`](S09_FINDINGS.md).

## Ограничения и остаточный риск

- Отсутствие сигналов **не доказывает отсутствия всех уязвимостей**. `--config auto` охватывает только доступные правила, а не все свойства безопасности из `security-requirements.md`.
- Semgrep фактически включил **9 C#-файлов из `src/`**. Файлы тестового проекта не вошли в итоговую выборку; примеры правил и файлы вне C#-области также не проверялись этим запуском.
- Semgrep отметил исключённые файлы по шаблонам и `.semgrepignore`; это не полный аудит Docker, конфигураций, зависимостей, IaC и ручных бизнес-логических угроз.
- Gitleaks проверил доступные refs и 24 коммита **локально имеющейся истории**, но не гарантирует отсутствие секретов в недоступных ветках, внешних системах, логах или скопированных ранее данных.
- Демонстрационный `POSTGRES_PASSWORD` в `.env.example` предназначен для локального стенда согласно комментарию в самом файле; это не считается подтверждённой утечкой действующего секрета. В production такие значения использовать нельзя.
- Первый запуск Gitleaks завершился кодом `126` из-за команды запуска, не как результат анализа. После исправления команды проверка выполнена успешно (`0`), что подтверждено повторным логом. Исходные отчёты Semgrep сохранены отдельно до/после.
- Исходное рабочее дерево содержало неотслеживаемую папку `reports/` (`git status --short`); Semgrep явно сообщил, что проверяет только tracked files, поэтому вывод не распространяется на эту папку.
